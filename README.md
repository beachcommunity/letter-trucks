# Letter Trucks

A truck game in the browser where a toddler learns lowercase letters and letter sounds. Bears order letters, you deliver them, and little letters get towed to their big letters.

- Play: open `dist/letter-trucks.html` in a browser. It's one self-contained file.
- Build: `python3 build.py`
- Test: `python3 tests/mktest.py && python3 tests/test_v3.py` (needs Python Playwright)

Pictures: [Twemoji](https://github.com/jdecked/twemoji) (CC BY 4.0). Voices were generated with Gemini TTS through OpenRouter.
